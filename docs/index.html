Overview

ScopeBee is a 2D-first engine that builds for the browser.

The editor

  1. Hierarchy

    The tree of objects in the open scene. Objects nest inside one another, and the one you select here is the one the Inspector shows. The plus button at the top adds a new object.

  2. Scene

    The scene view, where objects are placed and moved. The toolbar holds the tools for moving, rotating and scaling them; the Game tab next to it shows the scene through the camera.

  3. Project

    Every asset of the project: folders on the left, the contents of the open folder on the right. Scenes, prefabs, sprites, sounds and scripts all live here. The Console, Audio Mixer and Animation share this panel as tabs.

  4. Inspector

    The selected object and its components. Name, tag and layer come first, then the Transform and every component with its fields; Add Component puts a new one on the object.

Play in the editor

  1. Game

    The Game panel runs the game right inside the editor, and it plays there just as it does on the target platform.

  2. Play controls

    Play starts the game, pause stops it on the current frame, and the step button advances it by one.

Animation

  1. Animator

    The state machine behind an object's animations. Each state plays a clip, the arrows between states are transitions, and the parameters on the left — Float, Int, Bool and Trigger — are what the transitions check. Select a state or a transition to edit it under Properties.

  2. Animation

    The timeline of a single clip. Add Property picks what the clip changes — a sprite, a position, a colour — and Add Key sets its value on the current frame. The clip's frame rate is set here too, and Play and Preview run it in the editor without starting the game.
