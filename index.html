ScopeBee

Web-first, lightweight and performant game engine

COMINGSOON

Runtime

Engine

A runtime built around a single rule: ship the smallest binary that runs the fastest, identically on every platform.

  • Maximum performance
  • Minimal build size
  • Minimal RAM footprint
  • Uniformity across platforms

Language

Beef

The engine is written in Beef — a compiled language that reads like C# and runs like C++. There is no garbage collector, so a frame never stalls on cleanup you did not schedule.

  • Familiar syntax, native speed
  • No garbage collector
  • Code generated at compile time, not reflected at runtime

Tooling

Editor

An editor that starts instantly and stays out of your way. No launchers, no ceremony — open a project and work.

  • Lightweight
  • Extensible
  • No hub required

Migration

Unity converter

Bring an existing Unity project across instead of rewriting it. Scenes, prefabs and component data are converted, and C# scripts are translated into Beef.

  • C# → AST → Beef
  • Scenes and prefabs with their full hierarchy
  • Unity components mapped onto engine ones
  • Textures, sprites and animation clips

What's next

Roadmap

  1. AUG2026

    C# → Beef In progress

    The converter reaches deeper into the language: constructs that used to stop it now come across on their own.

    • Language coverage
    • Real projects, end to end
  2. SEP2026

    Binary assets and gizmos

    Scenes, prefabs and project data serialise into a compact binary form the runtime reads without parsing — and the editor takes full control of it: import, browse, reference, rebuild. The scene view gains handles of its own: move, rotate and scale an object without touching a number field.

    • Binary serialisation
    • Asset browser
    • References and dependencies
    • Gizmos
  3. OCT2026

    Particles and materials

    Effects get a system of their own, and materials gain depth: parameters, blend modes and presets shared across objects. The renderer stops paying for what nobody sees — sprites outside the camera frustum never reach a draw call.

    • Particle system
    • Material parameters
    • Blend modes and presets
    • Frustum culling
  4. NOV2026

    Sound, tilemaps and portals

    The engine gains a voice: sources, mixers and volume groups you set up once and control from anywhere. Alongside it, tile-based levels are assembled right in the editor — and a build learns to introduce itself to the outside world: Poki, CrazyGames, Yandex Games, VK Play, Facebook Instant Games, all behind one interface.

    • Audio system
    • Mixers
    • Tilemap
    • Web portals
  5. DEC2026

    3D for real

    The three-dimensional half leaves preview status behind: models come in with their materials, skeletons move, and bodies collide.

    • Model import
    • Skeletal animation
    • 3D physics
