Candy Balance: a Flash game, remade

A remake of a game that came out on Flash more than 14 years ago. Flash is long gone from the browser; the game is back in it, rebuilt on ScopeBee.

Play it in the browser

A remake, not a port

The original was a Flash game, and Flash stopped running in browsers at the end of 2020, taking thousands of games like it along. The remake is built in the ScopeBee editor, with the game code in Beef.

What is inside

What the game uses from the engine:

  • Tags — collision handlers identify the other body by its tag, so one rule covers every object with that tag.
  • Physics materials — friction and bounce per body; density and gravity scale on Rigidbody2D, including negative gravity.
  • Physics queries and impulses — OverlapCircle finds the bodies around a point, AddForce pushes them.
  • Joints — HingeJoint2D with angle limits.
  • Animator — state machines on the objects themselves, with the clip length read from the asset.
  • Audio — one-shot effects and streamed music.

What it weighs

A whole game with sound and music, measured the same way as every other figure on this site.

Transferred is what the browser downloads on a cold load; Resources is the size of everything the page loaded, as Chrome DevTools reports it on the Network tab. First frame is the line the build prints when its first frame is drawn. Heap snapshot is a Chrome DevTools heap snapshot on the idle main menu.

Try it

The build runs in the browser: turn the sound on and play a few levels.
